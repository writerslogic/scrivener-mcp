# Video production kit

Three short tutorials for writers who are new to AI tools. Each script lists the narration, what appears on screen, and what to capture, so anyone can record it.

| Video | Length | Goal |
|---|---|---|
| [1. Install in two minutes](./01-install.md) | 2:00 | A new user goes from download to a connected AI app |
| [2. Your first conversation with your manuscript](./02-first-conversation.md) | 3:30 | Show real writing help: orientation, feedback, safe revision |
| [3. Keeping your manuscript safe](./03-staying-safe.md) | 2:00 | Remove the fear of the AI damaging the book |

## Recording setup

- **Screen:** 1920 by 1080, a clean macOS desktop, light mode. Hide the Dock and notifications. Turn on Do Not Disturb.
- **Demo project:** use a copy of `tests/sample-project.scriv`, never a real manuscript. Rename it "The Lighthouse Keeper" so the on-screen text reads naturally.
- **AI app:** Claude Desktop for the main takes. Record a short B-roll clip in BoltAI and Raycast for the install video.
- **Cursor:** enable a click highlight and keep movements slow. Pause one second after each click.
- **Audio:** a quiet room, a USB microphone, no music over narration. Add soft background music only in the intro and outro, at low volume.
- **Captions:** upload an SRT file with every video. Many viewers watch without sound.
- **Privacy:** before each take, check that no account email, API key, or personal folder name is visible.

## Style rules

- Plain words. No "MCP server", "stdio", or "JSON" in narration. Say "connect your AI app to Scrivener".
- Show the result first, then how to get it.
- One idea per scene. Cut anything over eight seconds that has no on-screen change.
- Always state that the AI app needs its own account, so nobody is surprised.

## Where to publish

- A YouTube channel playlist, with the install video as the first item and pinned in the README.
- Embed each video on the matching docs page: install in `docs/install-mac.md`, safety in the README.
- Short vertical cuts (30 seconds, one prompt and its result) for social platforms.
- Read each community's self-promotion rules before posting. The Scrivener forums and subreddit often limit posts from tool authors, so lead with the tutorial's usefulness.

## Thumbnails

White text on the app's blue gradient. Three to five words: "Connect Scrivener to AI", "Ask your manuscript", "Edit without fear".
